# Validation suites

Each suite documents its inputs, run commands, outputs and interpretation limits.

- [dvh_accuracy](dvh_accuracy/README.md): 120-case synthetic axial DVH comparison with continuous truth and a shared dicompyler-core comparator.
- [dvh_extension](dvh_extension/README.md): 1,208-case synthetic DVH design covering small volumes, NIfTI masks and rotated dose grids.
- [ibsi](ibsi/README.md): Radiomics conformance against public IBSI 1 phantoms and reference features.
- [ibsi2](ibsi2/README.md): Production convolutional-filter comparisons against public IBSI 2 response maps and radiomics references.
