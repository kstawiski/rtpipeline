## 0. What B3 is (and the v2→rev2 correction)

For each **single 3-D scalar functional MR map** (ADC, scanner perfusion map, DCE subtraction) of a patient, bring it into the patient's anatomic-MR `total_mr` mask geometry and compute **per-structure summary statistics**. Output a per-series JSON sidecar + cohort CSV `mr_functional_structures.csv`. **DEFAULT-DENY**: only explicitly-recognized quantitative map subtypes are sampled; every other classified `mr_functional` series gets an auditable QC row and is excluded from the primary table. Failures fail-loud (one terminal QC status per discovered candidate). DCE-PK (Ktrans/Ve/Kep/AIF) explicitly DEFERRED.

**rev2 BLOCKER fix (Claude #1):** this cohort stores DCE/TWIST dynamics as **separate single-volume series per timepoint** (`t1_twist_tra_dyn_TT=7.0s`, … 244 TWIST + 335 `dyn` distinct descriptions). A multi-volume/4D guard does NOT catch these (each is one 3-D volume). rev1's "sample `other_functional`" would have emitted hundreds of rows of raw, arbitrary-scale dynamic signal as `qc==ok`. **rev2 routes by an explicit allow-list (default-deny); raw dynamics → `raw_source_pk_deferred` (audit row, excluded).** This matches the approved DESIGN (which enumerates in-scope = ADC/DWI + scanner maps TTP/PEI/WO/WI/SUB, never raw dynamics).

### 4.2 Per-patient algorithm
1. **Enumerate** from `all_series/metadata/series_manifest.json` (Claude #8): `mr_functional` candidates; `mr_anatomic` rows with `total_mr` segmentation present, mask dir resolved via `_series_artifact_dirs(...)/<base_name>/total_mr--multilabel.nii.gz` (+`--segmentations.json`). Tie-break field is `n_slices` (the manifest key; `n_instances` does NOT exist in the manifest).
2. **Load** the functional series via **dcm2niix** (Claude #4) so F shares the mask pipeline's NIfTI/ITK-LPS geometry convention; rescale is applied **once** by that load path — do NOT re-apply RescaleSlope/Intercept (Claude #5). Record load failures → `load_failed`; missing DICOM → `not_materialized`.
3. **Single-scalar-3D gate (Codex #3, Claude content-check):** accept only a single 3-D scalar volume. >1 volume (4D dynamic) → `multivolume_4d_pk_deferred`; multi-component/non-scalar/derived-display → `unsupported_non_scalar_functional`. MIP (`mip|maxip|minip|mipt` token or ImageType MIP) → `mip_excluded`.
4. **Subtype routing — DEFAULT-DENY (Claude #1, Codex-r2 MAJOR, Claude-r2 NEW-1, Claude-r3 MAJOR, Claude-r4 MAJOR), priority order.** **Token-matching semantics mirror the classifier's `_MR_FUNCTIONAL_RE` exactly (`modality_classifier.py:80-84`), per-token, in THREE buckets (Claude-r5):** (i) **substring** (vendor-fused, no separator): `adc`, `dwi` — matches `IsoADC`/`dADC`/`eADC`/`dRegADC`/`IsoDWI`/`cDWI`/`dDWI`/`eDWI`/`DWIBS` (~19 in-cohort Philips/GE maps; classifier `:77-79` rationale). (ii) **prefix-anchored, open-suffix** (`\b…`): `diff`, `ep2d`, `perf`, `dyn`, `subtract` — so full-word `Perfusion`/`Dynamic`/`Apparent Diffusion` are caught exactly as the classifier catches them. (iii) **standalone token** (`\b…\b` / token-SET membership): `twist`, `grasp`, `wo`, `wi`, `sub`, and the standalone DERIVED_MAP entries (`ttp`, `pei`, `relcbf`, `relcbv`, `relccbv`, `relmtt`, `pbp`) — **NEVER substring**, critical because `wi` is a substring of `twist` (244 raw TWIST in-cohort) and standalone-only membership keeps every TWIST raw out of `perfusion`. Applying token-set membership to `adc`/`dwi` would silently drop the vendor-fused maps to `unsupported_functional` and lose the headline ADC/DWI product for an entire vendor family (Claude-r4 MAJOR); applying it to `perf`/`dyn` would miss full-word `Perfusion`/`Dynamic` (Claude-r5) — hence the per-token buckets, which literally reproduce `_MR_FUNCTIONAL_RE`. The perfusion predicate is **derived-map-token-only**: `DERIVED_MAP = {ttp, pei, relcbf, relcbv, relccbv, relmtt, pbp, wo, wi}` (WO/WI = scanner wash-out/wash-in *maps* per DESIGN; relcb*/relmtt/pbp = GBM DSC-perfusion maps — see §6). Bare `perf` is NOT in `DERIVED_MAP` (it is the *raw acquisition* family: `ep2d_perf_p2`, `t1_vibe_tra_perf_CM`). **Order (the raw-`perf` defer MUST precede the DWI branch, because `ep2d_perf` shares the `ep2d` token with `ep2d_diff` DWI — Claude-r3 MAJOR):** (a) any `DERIVED_MAP` token → `perfusion` (mean/median); else (b) `adc`/apparent-diffusion → `adc` (mean/median/p10/p90); else (c) `sub`|`subtract`(token) → `subtraction` (mean/median); else (d) **`perf` token present (raw perfusion acquisition, no derived-map token) → `raw_source_pk_deferred`**; else (e) `dwi`|`diff`|`ep2d` single-b scalar → `dwi` (mean/median/p10/p90, `raw_unit=arbitrary`); else (f) other raw acquisitions (`dyn`|`twist`|`grasp`) → `raw_source_pk_deferred`; else `unsupported_functional`. Only `adc|perfusion|subtraction|dwi` are sampled; the rest emit audit rows excluded from the primary table. (Backstops: step-3 single-scalar-3D gate defers 4-D EPI-perf/DCE as `multivolume_4d_pk_deferred`; so `ep2d_perf_p2` lands `multivolume_4d_pk_deferred` when 4-D, `raw_source_pk_deferred` when single-volume — never sampled as `dwi`.)
5. **Anatomic-MR selection (Codex #1, Claude #8) — geometry-first, deterministic:** (a) candidate sharing F's `frame_of_reference_uid`; if several, rank by grid/affine similarity to F then acquisition-time proximity. (b) else same `study_uid`, rank by affine similarity + acq-time proximity. (c) if two candidates are within tolerance of equally good → `ambiguous_anatomic_match` (audit, excluded) rather than silently pick the longest. (d) none → `no_anatomic_match`. Record chosen `anatomic_series_uid` + basis. (`n_slices` only as a final deterministic tiebreaker.) **Source note (Claude-r2 NEW-3):** grid/affine similarity is computed from the loaded images; acquisition-time, if used, comes from a DICOM-header read of the candidate series (the manifest has no acq-time). Geometry-similarity + `n_slices` keep selection fully deterministic even if acq-time is unavailable.
6. **Geometry/registration tier → resample F onto the anatomic-mask grid (DESIGN direction; never reverse):**
   - same FoR & full-geometry match (origin/spacing/direction/size within tol) → `direct`.
   - same FoR, geometry differs → resample F→anatomic grid, **LINEAR** (continuous map; NN is label-only). tier `resample_samefor`.
   - different FoR → rigid Euler3D MI (Mattes 32-bin, multi-res shrink[4,2,1]/smooth[2,1,0], `CenteredTransformInitializer` MOMENTS, deterministic sampling), then resample F→anatomic LINEAR. tier `rigid_mi`.
   - **Registration acceptance is scale-invariant (Codex #5, Claude #6):** NOT a raw-MI threshold. Accept iff optimizer converged AND transform within plausibility bounds (|translation|, |rotation| ≤ caps for same-patient same-region) AND mask-region **coverage fraction** (fraction of structure-mask voxels receiving in-FOV F samples) ≥ threshold. Else `reg_failed` (audit, excluded).
7. **Per-structure stats** under each `total_mr` label (minimal reader): on the resampled F (grid A), compute the subtype's stats. **Record `n_native_voxels`** = count of native-F voxels under the structure (NN mask→F) alongside resampled `n_voxels`, so interpolation up-sampling is auditable (Claude #3); flag `low_native_voxels` (e.g. <10) — interpolation-dominated percentiles, kept but flagged (honors DESIGN's keep-small-structures intent without reversing direction). Empty mask → `empty_mask`. **Deformable-organ caveat (Claude #9):** on `rigid_mi` tier, structures in {bladder, rectum, bowel/colon, small_bowel} get `deformable_flag=true` (annotation reason `deformable_rigid_reg`: rigid can't model filling/peristalsis between sequences) — value emitted, flagged (separate column, not a qc_flag value).

### 4.3 Outputs & units provenance (Codex #4, Claude #5/#11)
Per-series JSON sidecar (registration block: tier, converged, transform params, coverage, anatomic uid+basis; per-structure stats; qc) + cohort CSV `mr_functional_structures.csv`: `patient_id, functional_series_uid, functional_series_description, functional_subtype, anatomic_series_uid, anatomic_basis, registration_tier, reg_converged, reg_coverage_frac, structure_name, n_voxels, n_native_voxels, low_native_voxels, mean, median, p10, p90, raw_unit, unit_source, rescale_applied, normalized_unit, qc_flag, deformable_flag, rtpipeline_version`. **Annotation columns vs terminal QC (Claude-r3):** `qc_flag` holds the single terminal series-level status; `low_native_voxels` (bool, derived from `n_native_voxels` < threshold) and `deformable_flag` (bool) are **separate non-exclusionary annotation columns** — they never overwrite `qc_flag`, so the "one terminal QC per series" invariant (§4.4) is preserved. **Units (impl rev — convention-permissive):** persist raw values + `raw_unit` + `unit_source` (`rwvm`|`rescale_type`|`convention`|`none`) + `rescale_applied` (bool); `normalized_unit` only when justified by metadata, else null. Every sampled subtype has a documented unit convention (ADC `10^-6 mm2/s`, DWI `arbitrary`, perfusion `map-specific`, subtraction `arbitrary`), so when RWVM/RescaleType are absent the unit falls back to `convention` (NOT dropped — "maximize data utilization"; matches the plan-r5 DWI-arbitrary-but-emitted decision). `unknown_units` is therefore a **RESERVED defensive QC** not auto-triggered in v1. `unit_source`/`raw_unit` never null (mandatory). Consumers MUST stratify by `functional_subtype`+`raw_unit`. Consumers MUST stratify by `functional_subtype`+`raw_unit`. **One terminal qc per discovered candidate**; non-`ok` rows emit qc + null stats (denominator integrity).

### 4.4 QC taxonomy (complete — Codex #9, Claude #12)
`ok`, `no_anatomic_match`, `ambiguous_anatomic_match`, `anatomic_out_of_scope`, `multivolume_4d_pk_deferred`, `unsupported_non_scalar_functional`, `unsupported_functional`, `raw_source_pk_deferred`, `mip_excluded`, `reg_failed`, `empty_mask`, `unknown_units`, `load_failed`, `not_materialized`. Plus non-exclusionary annotation columns (NOT qc_flag values): `low_native_voxels` (bool), `deformable_flag` (bool; reason `deformable_rigid_reg`). **Completeness invariant (series-granularity — Claude-r2 NEW-2):** every classified `mr_functional` series yields **exactly one terminal series-level QC status** and **≥1 CSV row** (one row per structure when `ok`; exactly one qc-row when excluded). Because the CSV is per-structure, the test asserts **set-equality of candidate series-UIDs between the manifest and the CSV** (no silent drop) — NOT a row count.

## 5. Tests (rtpipeline env; PYTHONPATH override)
1. Regex: 3 `…_SUB`→functional; anatomic regression; token-level P0 case-test; `\bsub\b|\bsubtract` rejects `subclavian`/`subcutaneous`.
2. Synthetic ADC same-FoR same-grid → exact mean/median/p10/p90 (`direct`).
3. Same-FoR **different-geometry** → linear-resample; values within tol; `n_native_voxels` recorded.
4. Rigid-reg shifted phantom → recovers transform within bounds; coverage ≥ threshold; sampled mean matches reference within tol; forced reg failure → `reg_failed` excluded.
5. Default-deny routing (token-set membership, NOT substring): `t1_twist_tra_dyn_TT=…`→`raw_source_pk_deferred` (asserts `wi`⊄`twist` token-membership — never `perfusion`); **single-volume `ep2d_perf_p2`→`raw_source_pk_deferred` (NEVER `dwi`; routing-order regression, Claude-r3)**; 4-D `ep2d_perf`→`multivolume_4d_pk_deferred`; `ep2d_diff`/`DWI_b1500`→`dwi`; `…_TTP`/`…_WO`→`perfusion`; `…_SUB_MIP_COR`→functional at discovery yet `mip_excluded` at sampling (two-stage, Codex #8); non-scalar→`unsupported_non_scalar_functional`.
6. QC paths: empty mask→`empty_mask`; no/ambiguous anatomic; config precondition unmet→warn + `anatomic_out_of_scope`.
7. Units: slope≠1/intercept≠0 applied **once** (no double-scale); absent RWVM/RescaleType → `unit_source=convention` (NOT excluded — convention-permissive, see §4.3); `unknown_units` reserved.
8. Completeness: candidate series-UID **set-equality** (manifest ↔ CSV) + one terminal series-level QC each; `ep2d_perf_p2`/`t1_vibe_tra_perf_CM` (bare-`perf` raw) → deferred (not `perfusion`); a derived `…_TTP`/`…_WO` map → `perfusion` sampled. Opt-in default-off (flag absent → no CSV, no behavior change); idempotent re-run skips existing sidecars.

## 6. Deviations from literal DESIGN (flagged for Round-2)
- `\bsub`→`\bsub\b|\bsubtract` (cross-cohort safety; cohort-equivalent). 
- Default-deny subtype routing (DESIGN enumerates the in-scope set; rev2 makes "everything else excluded" explicit — not a scope change, a safety hardening).
- `n_native_voxels` audit + `low_native_voxels` flag added on top of DESIGN's functional→anatomic linear resample (does NOT reverse the approved direction).
- Metadata/content gating (single-scalar-3D, ImageType) added as correctness guards beyond description tokens.
- **rev3:** perfusion sampled on derived-map tokens only (bare `perf` raw-acquisition defers); WO/WI added as derived wash-maps (reconciles regex↔sampler, honors DESIGN's "WO/WI maps"); completeness invariant stated at series granularity (UID set-equality).
- **rev4:** `DERIVED_MAP` adds GBM DSC-perfusion tokens (`relcbf|relcbv|relccbv|relmtt|pbp`) beyond DESIGN's literal pelvic list `TTP/PEI/WO/WI/SUB` — necessary + design-intent-faithful ("sample existing scanner-derived maps"; prevents under-sampling real GBM DSC maps in the multi-cohort tree), documented here as a scope addition. Routing order fixed so raw-`perf` defers BEFORE the DWI branch (`ep2d_perf` no longer mis-sampled as `dwi`).
- **rev5:** scoped the token-matching rule to match the classifier's proven `_MR_FUNCTIONAL_RE` convention per-token — `adc`/`dwi` are **substring** matches (so vendor-fused `IsoADC`/`dADC`/`IsoDWI`/`cDWI`/`DWIBS` maps are sampled, not dropped to `unsupported_functional`); only the ambiguous short tokens (`wo|wi|sub|perf|dyn|twist|grasp` + DERIVED_MAP) are token-set/`\b`-bounded. Reconciled the `deformable_flag` column name vs the `deformable_rigid_reg` reason. This mirrors existing, tested classifier behavior (no new matching scheme).
