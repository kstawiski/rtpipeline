# Code of conduct

RTpipeline follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Participants commit to respectful, harassment-free collaboration in issues, pull
requests, reviews and any other project space.

Report unacceptable behaviour privately to the maintainer through GitHub's private
reporting channel for this repository. Do not include patient data, credentials or
production logs in a report. Reports are reviewed confidentially, and contributions
or participants that breach this code may be removed or blocked.
